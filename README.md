# 📖 Hece Hece Okuyorum

Çocukların hece ve kelime okumayı adım adım çalışması için hazırlanmış basit, mobil uyumlu bir web uygulaması.

## 🎯 Amaç

Uygulamanın amacı çocuğun:

1. Harf veya heceleri tek tek okuması
2. Bunları birleştirerek sonucu okuması
3. Aynı çalışmayı gerektiğinde tekrar etmesi
4. Önceki ve sonraki çalışmalara geçebilmesi

Örneğin:

**a + t → at**

Çocuk önce parçaları okur. **Doğru** düğmesine basıldığında birleşmiş sonuç gösterilir.

## 📱 Kullanım

Uygulama telefonda, tablette ve bilgisayarda çalışır.

### Düğmeler

- **← Önceki:** Bir önceki çalışmaya döner.
- **↻ Tekrar:** Bulunulan bölümün en başına döner.
- **✓ Doğru:** Birleştirme çalışmasında sonucu gösterir.
- **Sonraki →:** Sonraki çalışmaya geçer.

## 🌐 GitHub Pages

Bu proje tek bir `index.html` dosyasıyla çalışır.

GitHub'da:

**Settings → Pages → Deploy from a branch → main → /(root)**

seçildiğinde proje GitHub Pages üzerinden yayınlanabilir.

GitHub'a yeni bir `index.html` gönderildiğinde GitHub Pages siteyi otomatik olarak yeniden yayınlar.
